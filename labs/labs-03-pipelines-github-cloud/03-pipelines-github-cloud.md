# Lab 3: Pipelines en GitHub manipulando cloud

Workflows que **interactúan con proveedores cloud** : provisionar infra con IaC, desplegar en Kubernetes gestionado, publicar imágenes en un registry, etc. El objetivo es llevar lo aprendido en el pipeline básico y en DevSecOps a un entorno real: CI/CD que construye, valida y despliega usando infra y servicios en la nube.
