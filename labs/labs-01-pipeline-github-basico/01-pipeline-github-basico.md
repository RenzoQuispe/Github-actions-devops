# Lab 1: Pipeline en GitHub básico (sin cloud)

Pipeline que corre **solo en GitHub** (runners hospedados), sin conectar proveedores cloud ni servicios externos que requieran credenciales. El objetivo es aprender la sintaxis de workflows (eventos, jobs, steps), usar artefactos y caché si aplica, y opcionalmente secrets/variables del repo, sin depender de AWS, GCP, Azure ni registries externos.
